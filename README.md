# منصة حسام بحر للأعمال والمعاملات في الإمارات

منصة عربية تجمع المعرفة والتوجيه والوصول إلى الجهات الرسمية لخدمات الأعمال والمعاملات الحكومية في دولة الإمارات.

## المتاح حالياً — المرحلة الأولى

- واجهة موحدة تغطي الإمارات السبع والخدمات الاتحادية.
- محرك بحث حسب اسم المعاملة أو المشكلة أو الإمارة أو المجال.
- تمييز واضح بين المسار الرسمي المباشر، وبوابة الجهة، والدليل الإرشادي داخل المنصة.
- أدلة متخصصة لخدمات MOHRE والإقامة والهوية والموافقات الحكومية في دبي.
- دليل يضم 2,610 أنشطة اقتصادية فريدة في دبي.
- صفحات إرشادية للتأسيس والإقامة والضرائب وكفالة الأسرة.
- إخلاء مسؤولية واضح يؤكد أن المنصة خاصة وليست جهة حكومية.

## منهج الروابط الرسمية

كل خدمة تحتوي على نوع وجهة واضح:

- `direct`: مسار رسمي مباشر إلى الخدمة أو رحلة المعاملة.
- `portal`: بوابة الجهة الرسمية عندما لا يتوفر رابط ثابت لمعاملة منفردة.
- `guide`: دليل داخل منصة حسام بحر يشرح المسار ويربط بالمصادر الرسمية.

تُراجع الرسوم والمتطلبات والمدد على موقع الجهة المختصة قبل تقديم الطلب، لأن البيانات الحكومية قابلة للتحديث.

## خارطة المنتج

### المرحلة الثانية — منصة الشركات

- حسابات وتسجيل دخول آمن.
- ملف موحد للشركة.
- خزنة مستندات مشفرة.
- صلاحيات للمستخدمين والموظفين.
- تنبيهات انتهاء ومؤشر امتثال.
- لوحة موارد بشرية وسجل معاملات وتقويم.

### المرحلة الثالثة — منصة التنفيذ

- تقديم ومتابعة الطلبات.
- دفع إلكتروني وفواتير.
- تكاملات API رسمية عند توفر الاتفاقيات والصلاحيات.
- شبكة شركاء ومقدمي خدمة معتمدين.

## حدود الأمان الحالية

الموقع منشور كواجهة ثابتة على GitHub Pages. لذلك لا تُستخدم الواجهة الحالية لحفظ جوازات أو هويات أو عقود أو بيانات دفع. ملف `admin.html` نموذج قديم محلي فقط وليس لوحة إدارة حقيقية، ويجب استبداله بخلفية آمنة وتسجيل دخول وصلاحيات قبل أي استخدام فعلي.

أُضيفت مواصفات الانتقال الآمن إلى التشغيل الحقيقي دون تفعيل أي جمع للبيانات الحساسة قبل جاهزية البيئة:

- [البنية الإنتاجية وخطة الإطلاق](docs/production-architecture-ar.md)
- [عقد واجهة البرمجة](api/openapi.yaml)
- [نموذج قاعدة البيانات](database/schema.sql)
- [سياسة الأمان](SECURITY.md)
- [إعدادات التشغيل العامة الآمنة](config/runtime.example.js)

تتحقق أداة `scripts/validate-foundation.py` من هذه الحدود قبل النشر. تبقى ميزات الحسابات والمستندات والدفع والمتابعة الحية معطلة افتراضياً حتى تجهيز الاستضافة الآمنة والحسابات القانونية اللازمة.

افتح `index.html` لمعاينة الموقع محلياً.
