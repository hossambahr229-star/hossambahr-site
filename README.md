# موقع Hossam Bahr Business Services

افتح `index.html` لتشغيل الموقع، و`admin.html` لفتح لوحة الإدارة التجريبية.

## ما يعمل حاليًا

- عرض وبحث أكثر من 70 خدمة حكومية.
- طلب خدمة وإنشاء رقم معاملة تلقائي.
- تتبع الطلب من رقم المعاملة.
- لوحة CRM محلية لعرض الطلبات وتحديث حالتها وتصديرها.
- اتصال وواتساب مباشر على الرقم 0503780460.
- تصميم عربي متجاوب ومحسّن لمحركات البحث.

## مهم قبل النشر

لوحة الإدارة الحالية نموذج تجريبي يحفظ البيانات داخل متصفح الجهاز فقط (`localStorage`). للاستخدام الحقيقي يجب ربطها بخادم وقاعدة بيانات، إضافة تسجيل دخول وصلاحيات، تشفير وحماية، وإشعارات واتساب أو SMS. كما يجب استبدال موقع دبي العام في الخريطة بعنوان الشركة الدقيق وإضافة بيانات الترخيص وسياسة الخصوصية.
