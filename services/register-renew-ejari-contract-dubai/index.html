تسجيل أو تجديد عقد إيجاري في دبي

تسجيل عقد الإيجار أو تجديده في نظام إيجاري وإصدار شهادة تسجيل إلكترونية.

الاسم الرسمي: Register / Renew Tenancy Contract

بطاقة خدمة حكومية متحققة: الرابط يفتح بطاقة المعاملة المحددة لدى دائرة الأراضي والأملاك في دبي / مؤسسة التنظيم العقاري، وليس صفحة رئيسية أو خدمة مشابهة.

المستندات والمتطلبات

  • عقد الإيجار الموحد
  • هوية مقدم الطلب
  • وكالة رسمية عند التقديم بواسطة ممثل

الشروط

تختلف قناة التقديم حسب إدارة العقار وصفة المالك والمستأجر، ويتطلب اعتماد الطرف الآخر في بعض القنوات.

الرسوم الرسمية المنشورة

177.75 درهمًا عبر التطبيق أو الموقع، أو 220 درهمًا عبر مركز أمين الخدمات العقارية وفق الرسوم المنشورة.

مدة الإنجاز

25 دقيقة عبر مركز الخدمة، بخلاف الانتظار

خطوات التنفيذ

  1. فتح بطاقة الخدمة الرسمية.
  2. اختيار القناة المتاحة وتسجيل الدخول عند الحاجة.
  3. إدخال البيانات وإرفاق المستندات.
  4. سداد الرسوم واستلام المخرج الرسمي.

الأسئلة الشائعة

هل الرابط خاص بهذه المعاملة؟

نعم، تمت مطابقة عنوان الرابط ومحتواه مع المعاملة المحددة.

هل يمكن أن تتغير الرسوم؟

تعرض الجهة الحكومية القيمة النهائية قبل السداد، وتختلف بعض الرسوم بحسب النوع أو القناة.
