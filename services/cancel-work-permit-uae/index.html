المسار الداخلي خاص بهذه الخدمة ولا يحوّلك إلى صفحة جهة عامة. تفتح بطاقة الخدمة الرسمية الدقيقة؛ يبدأ التنفيذ من زر الجهة داخل البطاقة وقد يتطلب تسجيل الدخول.

  • بيانات التصريح والعقد
  • طلب الإلغاء وتوقيع الأطراف بحسب الحالة
  • إقرار أو إثبات تسوية المستحقات
  • ترتيب الخطوة التالية للإقامة والهوية

خطوات التنفيذ

  1. فتح المصدر الرسمي

    افتح بطاقة الخدمة الحكومية الرسمية المرتبطة بهذه المعاملة.

  2. تأكيد نطاق المعاملة

    طابق اسم المعاملة والإمارة وصفة مقدم الطلب مع الحالة التي تريد إنجازها.

  3. مراجعة المتطلبات الحالية

    راجع المتطلبات والمستندات والرسوم المعروضة في المصدر الرسمي قبل بدء الطلب.

  4. تقديم الطلب رسميًا

    سجّل الدخول بالقناة التي تحددها الجهة، وأدخل البيانات وأرفق المستندات المطلوبة.

  5. السداد والمتابعة

    سدّد المبلغ الذي تعرضه الجهة عند انطباقه، واحتفظ برقم الطلب لمتابعة النتيجة.

المسار الرسمي الصحيح

بطاقة رسمية خاصة بهذه الخدمة.

افتح البطاقة ثم استخدم زر بدء الخدمة داخل موقع الجهة. لا نعرض صفحة الجهة العامة على أنها رابط تنفيذ.
