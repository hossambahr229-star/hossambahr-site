خدمة لأصحاب العمل والموظفين لتسجيل مطالبة عمالية عند إخلال أحد الطرفين بالتزاماته التعاقدية، ومحاولة التسوية الودية قبل الإحالة للقضاء عند الحاجة.

تنبيه: HossamBahr منصة إرشادية مستقلة وليست جهة حكومية. القبول والرسوم النهائية وقرار المعاملة للجهة المختصة.

من يمكنه طلب الخدمة؟

موظفصاحب شركةممثل منشأةمستثمر

الشروط

  • أن يكون الموظف مسجلاً في قاعدة بيانات الوزارة
  • ألا توجد للموظف نفسه شكوى معلقة أو نزاع محال إلى المحكمة، إلا إذا كانت علاقة العمل مستمرة أو كان الموظف يريد إلغاء تصريح العمل

المستندات المطلوبة

  • مستندات تؤيد المطالبة عند توفرها، مثل خطاب الاستقالة أو الفصل

الرسوم

  • رسوم الخدمة: 0 AED

قد تتغير الرسوم بحسب القناة والحالة ومدة التصريح؛ راجع الحاسبة أو صفحة الجهة قبل الدفع.

خطوات التقديم

  1. سجّل الدخول إلى قناة الوزارة الرسمية بحساب المنشأة أو الهوية الرقمية.
  2. اختر الخدمة وأدخل بيانات المنشأة والعامل بحسب الحالة.
  3. ارفع المستندات المطلوبة وأرسل الطلب من حساب المخول بالتوقيع.
  4. استكمل أي نواقص ترسلها الوزارة وتابع حالة المعاملة رسمياً.
  5. بعد الموافقة، سدد الرسوم التي تعرضها القناة الرسمية واحفظ رقم الطلب.

هذه خطوات إرشادية للوصول الآمن؛ التفاصيل التنفيذية النهائية تظهر داخل قناة الجهة الرسمية.

الحالات الخاصة

  • تحاول الوزارة التسوية الودية أولاً
  • يمكن إحالة النزاع إلى المحكمة المختصة عند تعذر التسوية
  • قد يلغى تصريح العمل إذا تطلبت المطالبة ذلك

أسباب الرفض المحتملة

  • عدم تسجيل الموظف في قاعدة بيانات الوزارة
  • وجود شكوى معلقة أو نزاع قضائي قائم للحالة نفسها دون انطباق الاستثناء المنشور

أسباب التأخير

  • تعذر التواصل مع أحد طرفي الشكوى أو تأخر تقديم المستندات المؤيدة
  • الحاجة إلى جلسة إضافية أو رأي المستشار القانوني قبل التسوية أو الإحالة

أخطاء شائعة

  • إدخال رقم منشأة أو جواز أو هوية غير مطابق لسجلات الوزارة
  • تقديم مطالبة جديدة بينما توجد شكوى معلقة للحالة نفسها

حلول المشكلات

  • طابق بيانات الهوية والجواز والمنشأة مع سجلات الوزارة قبل إرسال الشكوى
  • أرفق ما يتوفر من عقد العمل وكشوف الراتب وخطاب الاستقالة أو الفصل لدعم المطالبة
