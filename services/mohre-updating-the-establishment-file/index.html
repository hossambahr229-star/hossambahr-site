تحديث ملف المنشأة

Updating the Establishment File

تعديل أو تغيير بيانات المنشأة المسجلة لدى وزارة الموارد البشرية والتوطين بعد تسجيل التعديل لدى جهة الترخيص وتحديث بطاقة ICP.

تنبيه: HossamBahr منصة إرشادية مستقلة وليست جهة حكومية. القبول والرسوم النهائية وقرار المعاملة للجهة المختصة.

من يمكنه طلب الخدمة؟

صاحب شركةممثل منشأةمستثمرموظف

الشروط

  • رخصة تجارية سارية
  • تسجيل التعديل لدى دائرة الاقتصاد وتحديث بطاقة المنشأة لدى ICP
  • ألا يقل عمر المرخص له أو وكيل الخدمات عن 21 سنة مع الاستثناءات المنشورة
  • وجود بطاقة منشأة صادرة من جهة الإقامة للمرخص له أو وكيل الخدمات
  • أن يكون المفوض لدى MOHRE مفوضاً أيضاً لدى ICP

المستندات المطلوبة

  • نسخة الرخصة التجارية الصادرة من جهة الترخيص
  • نسخة واضحة من وجهي بطاقة منشأة ICP
  • عقد إيجار بالبيانات والقيمة المحدثتين، باستثناء المنشآت الافتراضية
  • نسخة الهوية أو الإقامة التي تبين الرقم الموحد
  • ملحق الشركاء للمنشآت ذات الشكل الاعتباري

الرسوم

  • رسوم تقييم: 406 AED
  • الحد الأقصى لعمولة مركز الأعمال: 72 AED
  • رسوم خدمة موقع الوزارة أو التطبيق: 0 AED

قد تتغير الرسوم بحسب القناة والحالة ومدة التصريح؛ راجع الحاسبة أو صفحة الجهة قبل الدفع.

خطوات التقديم

  1. سجّل الدخول إلى قناة الوزارة الرسمية بحساب المنشأة أو الهوية الرقمية.
  2. اختر الخدمة وأدخل بيانات المنشأة والعامل بحسب الحالة.
  3. ارفع المستندات المطلوبة وأرسل الطلب من حساب المخول بالتوقيع.
  4. استكمل أي نواقص ترسلها الوزارة وتابع حالة المعاملة رسمياً.
  5. بعد الموافقة، سدد الرسوم التي تعرضها القناة الرسمية واحفظ رقم الطلب.

هذه خطوات إرشادية للوصول الآمن؛ التفاصيل التنفيذية النهائية تظهر داخل قناة الجهة الرسمية.

الحالات الخاصة

  • تعفى المنشآت الافتراضية من عقد الإيجار
  • يجب إتمام التعديل لدى جهة الترخيص وICP قبل MOHRE
  • لا تشمل الرسوم الضريبة ورسوم التحصيل

أسباب الرفض المحتملة

  • عدم تسجيل التعديل لدى جهة الترخيص أو عدم تحديث بطاقة ICP
  • انتهاء الرخصة أو عدم تطابق بيانات الوثائق المحدثة

أسباب التأخير

  • انتظار انعكاس تعديل الرخصة أو بطاقة ICP في الأنظمة
  • نقص عقد الإيجار المحدث أو ملحق الشركاء

أخطاء شائعة

  • التقديم إلى MOHRE قبل تحديث ICP
  • رفع الرخصة الجديدة مع عقد إيجار أو ملحق شركاء قديم

حلول المشكلات

  • أكمل التعديل لدى جهة الترخيص ثم ICP أولاً
  • طابق التاريخ والعنوان والشركاء والمفوضين في كل الوثائق

الأسئلة الشائعة

ما ترتيب تحديث الجهات؟

جهة الترخيص أولاً، ثم بطاقة المنشأة لدى ICP، ثم ملف MOHRE.
